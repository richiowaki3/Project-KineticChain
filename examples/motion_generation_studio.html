なぜ「下半身」と「上半身」を分離して生成するのか？

従来の全身一括生成AI（Diffusionモデル等）では、足の滑り（Foot Skating）や、全身がのっぺりと平均化されてダンス特有のキレ・質感が失われる問題がありました。 本アーキテクチャでは、「重さ・リズム・接地」を司る下半身と、「オノマトペ・感情・運動連鎖」を司る上半身を独立して生成し、「生体力学バランス（CoM/ZMP）」を司る体幹カプラーで物理的に結合することで、滑らない力強いステップと繊細な表現質感を両立します。

① 下半身：重さ・リズム軸 接地拘束（速度=0）、ビート同期、衝撃加速度、垂直ドロップによる重厚感
② 上半身：質感・オノマトペ軸 橈骨系（開き）vs 尺骨系（巻き）、仮想剛性・粘性（K, B）、急峻度（Jerk）
③ 体幹・全体：生体力学カプラー 重心（CoM）と圧力中心（ZMP）の足底支持面（BoS）制御、脊柱カウンターバランス

AIダンスパートナーとのリアルタイム対話（Call & Response）機構

下半身と上半身を分けた真価は、「相手のステップに合わせながら、上半身の表情（質感）で掛け合いを行う」というプロダンサーの即興対話が計算機上で実現できる点にあります。 下半身レイヤーが相手との距離とグルーヴ（リズム）を一定に保ち、上半身レイヤーが相手の繰り出したオノマトペ質感に呼応して「同調」「対比」「受け流し」を生成します。

1

同調モード (Unison / Mirroring)

人間のダンサーが「パキッ」と鋭くアクセントを打った時、AIパートナーも同じタイミングで高剛性(K)とJerkを発動し、一体感を強調します。

TargetTexture = PartnerTexture
PhaseDelay = 0 frames
2

対比・応答 (Call & Response)

人間の「ドシッ」とした強い着地アタックに対し、AIパートナーは「サラッ」と浮遊感のある脱力旋回で受け流し、ダンスの劇的なダイナミクスを生み出します。

TargetTexture = Invert(Weight, Flow)
ResponseDelay = 1 bar (小節応答)
3

ポリリズム対位法 (Counterpoint)

人間が上半身の大きな表現を行っている間、AIは裏拍の細やかな足元ステップ（尺骨系ステップ）を刻み、互いの空白を補い合います。

LowerBody = SyncBeat(Offset=0.5)
UpperBody = FocusComplement()

リアルタイム対話タイムライン（16ms 制御ループ）

Step 1: 計測 相手のカメラ映像 / センサーから 4D-Humans または MediaPipe で 3D ポーズ推定（16ms）
Step 2: 特徴抽出 当リポジトリの TextureProfiler と FootContactAnalyzer により、相手の接地状態・オノマトペベクトル（6D）を瞬時推定
Step 3: 方針決定 対話戦略（同調・応答・対位法）に基づき、AI側の下半身目標ステップと上半身目標オノマトペを計算
Step 4: 統合生成 下半身シーケンサー＋上半身変調器＋生体力学カプラーにより、VRM 49ノードポーズを生成してアバターにストリーミング

src/generation/lower_body_sequencer.py 足元接地・重さシーケンサー 
class LowerBodySequencer:
    """下半身の接地フェーズ、重さ衝撃度、ビート同期ステップを生成"""
    def generate_step_phase(self, bpm: float, weight_heaviness: float, duration_frames: int):
        # 重さが高いほど接地時間(Stance Phase)比率が増加、垂直降下幅大
        stance_ratio = 0.5 + 0.25 * weight_heaviness
        pelvis_drop = 0.05 * weight_heaviness  # 沈み込み (m)
        
        # 接地中の足裏速度をゼロに固定 (Foot-Locking Constraint)
        foot_poses = self._solve_leg_ik(pelvis_drop, stance_ratio, lock_velocity=True)
        return foot_poses, pelvis_drop

class UpperBodyTextureModulator:
    """764語オノマトペ辞書と連動し、仮想インピーダンス(K, B)で腕・胸郭軌道を制御"""
    def synthesize_arm_chains(self, onoma_entry: OnomaEntry, base_gesture: np.ndarray):
        K_stiffness = onoma_entry.acoustic.hardness * 25.0
        flow_damping = (9 - onoma_entry.effort.flow) * 3.5
        radial_bias = onoma_entry.effort.space / 9.0  # 橈骨系(リーチ) vs 尺骨系(巻き)
        
        # 2次遅れ系微分方程式: M*x'' + B*x' + K*(x - x_target) = 0
        modulated_rotations = self._solve_impedance(base_gesture, K_stiffness, flow_damping, radial_bias)
        return modulated_rotations

class WholeBodyBalanceCoupler:
    """下半身足位置と上半身慣性を結合し、転倒防止と自然な脊柱曲率を保証"""
    def couple_and_stabilize(self, lower_poses, upper_poses):
        com = self.calculate_center_of_mass(lower_poses, upper_poses)
        bos_polygon = self.get_base_of_support(lower_poses)
        
        # 上半身の傾きに対して骨盤を逆位相シフト (Pelvic Sway Compensation)
        if not bos_polygon.contains(com.xy):
            pelvis_offset = self.solve_zmp_equilibrium(com, bos_polygon)
            upper_poses, lower_poses = self.adjust_spine_chain(pelvis_offset)
            
        return self.assemble_vrm_humanoid(lower_poses, upper_poses)
